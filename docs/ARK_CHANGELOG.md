# Ark 更新日志

这里仅记录 `frame_film_ark` 固件与 Flutter Ark App 的联合发布。只有新增加的正式发布节会在推送到 `main` 且两项构建成功后创建 GitHub Release。

## [Unreleased]

- App 通行证上传接入 WiFi 直传，统一使用现有临时直连组、进度、取消和清理流程；按顺序保存位图与 JSON，并回读资料，失败后可从头重试上次上传。固件增加 0x5A 指定路径文件接收及 0x59 能力 bit1；旧固件需先升级，网页仍使用 BLE 上传。
- 头像编辑复用 Film 自适应抖动，新导入默认自动选择算法与强度；移除档案画面的头像尺寸标注。
- 修复彩色通行证首次打开或从空状态载入时向上错位、顶部内容被裁切的问题：先切换占位面板可见性并完成布局，再记录彩色卡片坐标。模拟器同步检查实际传给彩色显示层的位置。
- 彩色通行证改用 Film 同款 ColorFast 两阶段彩色快刷，沿用现有六色资料文件；实际色彩及包含切换清屏在内的耗时需实机确认。

## [2026.10.16.2] - 2026-10-16

App: 0.4.1+5

- 包含下方 2026.10.16.1 的 App 与固件改进；该次发布由本次替代。
- 新设备及恢复默认后的 LED 默认使用上游“自动”模式，无操作约 20 秒后熄灯；按键或蓝牙连接状态变化后重新亮起。升级继续保留已有用户设置。
- App 使用发行签名，首次从旧 debug 签名正式包迁移前需备份本地资料；最低 Android 9，`.dev` 开发包可并行保留。
- 固件以构建指纹识别更新，显示版本仍为 3.2.5。本次尚未完成真实设备升级验收。

## [2026.10.16.1] - 2026-10-16

App: 0.4.1+5

- App 使用固定发行签名，支持应用内下载更新、查看进度、取消与重试，下载完成后交给 Android 系统安装。
- 页面切换加入淡入与位移动画；连接设备并完成初始化后自动读取当前目录文件。
- 干员头像支持黑白、灰度和六色显示，支持构图位置、缩放、旋转、亮度、对比度、饱和度与抖动调整；本地保留源图和编辑参数。
- 合并上游蓝牙名称存储重构、LED 自动模式、休眠准备、文件列表扫描、开机切图修复及 ForFilm Web Serial 烧录功能。
- 固件增加 v5→v6 参数迁移，保留旧系统设置与自定义蓝牙名；保留 0x59 彩色通行证能力查询。
- 固件 OTA 包与完整烧录、调试附件分开；固件仍显示 3.2.5，以实际构建指纹识别是否相同。

安装说明：最低 Android 9。旧 debug 签名正式包不能直接覆盖安装此发行签名包，首次迁移前请备份 App 本地资料；`.dev` 开发版可并行保留。以后使用相同发行密钥且更高 versionCode 的版本可通过 App 内更新。

验证边界：本次提供编译、定向测试与模拟器检查结果，不代表已完成本次固件在实体设备上的升级和屏幕验收。
